# Installer & icon artwork

Generated by `scripts/make-branding.js` (see its header for how to run it) and committed,
so a release build needs nothing but this folder.

| File | Used by | Size |
|---|---|---|
| `icon-1024.png` | Source for `npx tauri icon` → `../icons/` (all platforms) | 1024×1024, transparent |
| `installer-header.bmp` | Windows NSIS `.exe` — wizard header | 150×57 |
| `installer-sidebar.bmp` | Windows NSIS `.exe` — welcome/finish page column | 164×314 |
| `wix-banner.bmp` | Windows MSI — top banner (light on the left: WiX draws the page title there in black) | 493×58 |
| `wix-dialog.bmp` | Windows MSI — welcome/finish dialog (light on the right for the same reason) | 493×312 |
| `dmg-background.png` | macOS DMG window background; app at (180,170), Applications at (480,170) | 660×400 |

Wired up in `../tauri.conf.json` under `bundle.windows.nsis`, `bundle.windows.wix` and
`bundle.macOS.dmg`.
